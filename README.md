# Ashfall Fire Co. — Career Simulator

A text-driven career simulator for firefighters and paramedics. Build a career with the Ashfall Fire Department, make tactical decisions in the field, manage crew relationships, and navigate the exams and politics of the fire service.

## Play

Download the installer from [Releases](https://github.com/KBradford94/ashfall-fire-co/releases) and run it. Windows will show a security warning — click **More info**, then **Run anyway**. (It's unsigned because signing costs hundreds a year; this is safe.)

Nothing is installed to your system. To uninstall, delete the folder. Saves live in `%APPDATA%\ashfallfireco\`.

## Features

**Two career tracks:**
- Suppression: engine companies, trucks, squads
- EMS: paramedics, field supervisors, chiefs

**Progression:**
- Fire Academy or Paramedic Academy to start
- Rank system with written and oral board exams
- Character arcs tied to crew members
- Incident command on structural fires, medical calls, technical rescues

**Mechanics:**
- Crew bonds, stress, and injuries carry weight
- Tactical choices affect outcomes
- Economy simulation — resources matter
- Save anywhere, load anytime

## About

Built in Electron with vanilla JavaScript and procedurally generated content. No frameworks, no build step in development. Designed to play in 15-minute sessions.

If you play it, the most valuable feedback is: did you want to keep playing after the academy? Where did you get stuck or confused?
